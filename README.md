# Claude 위젯

클로드 데스크탑 앱 옆에 띄워 두는 작은 창. 위에는 컨텍스트 사용량과 플랜 한도가, 아래에는
탭 네 개로 세션 목록이 나온다.

| 탭 | 무엇 |
|---|---|
| **확인 필요** | 입력·답변을 기다리는 세션(노랑)과 읽지 않은 응답이 있는 세션(파랑) |
| **실행 중** | 지금 일하고 있는 세션(실행 중·브라우저 사용 등) |
| **즐겨찾기** | 내가 챙기려고 골라 둔 세션 |
| **최근** | 턴이 끝난 세션, 최근 작업순, 시간대별 구분선 |

모두 앱 화면의 접근성 정보와 앱이 남기는 세션 파일을 읽어 온다. 앱을 고치거나 건드리지
않는다. 예전 이름은 "Claude 컨텍스트 위젯"이다.

```
24.9%   248.6k / 1.00M
주간·모든 모델 80% · 6시간 57분 후 초기화
[확인 필요 2] 실행 중 1  즐겨찾기  최근      ← 탭. 확인할 게 있으면 노랑·파랑
● PhotobookServer 리뷰                ✕      ← 누르면 이동, ✕ 는 숨김
   photobook-server-workspace · 3분째 대기
```

## 필요한 것

- 윈도우 10 / 11
- 클로드 데스크탑 앱이 **켜져 있고 한국어 UI**일 것

앱 화면의 글자를 읽는 방식이라 UI 언어를 탄다. 영어 UI에서는 컨텍스트 수치(`Context 325.8k
/ 1M`)까지는 읽지만 아랫줄(플랜 한도)은 비어 있을 수 있다. 다른 언어는 `알 수 없음` 만 뜬다.

## 빠른 시작

[Releases](../../releases) 에서 `ClaudeWidget.exe` 를 받아 더블클릭. 파이썬 없이
이 파일 하나로 돈다.

소스로 돌리려면 저장소를 받아 `클로드위젯.cmd` 더블클릭(콘솔 창 없이 뜬다).
표준 라이브러리 외에 `comtypes` 만 있으면 된다. 개발·빌드는 파이썬 3.13에서 했다.

```bash
pip install comtypes
```

설정과 로그는 **실행한 파일 옆에** 생긴다. exe를 바탕화면에 두면 바탕화면에 생기므로,
폴더 하나 만들어 그 안에 두는 편이 깔끔하다.

## 화면

- **윗줄** — 왼쪽에 컨텍스트 사용률을 크게, 오른쪽에 사용 토큰 / 상한을 작고 흐리게.
- **막대** — 같은 값. 값이 바뀌면 0.3초 동안 새 길이로 미끄러진다.
- **아랫줄** — 플랜 한도 쪽 정보. 앱 문구를 한 줄로 정리해 옮긴다.
- **탭** — 머리 아래 네 개. 고른 탭은 저장된다. 밑줄이 고른 탭으로 미끄러져 옮겨 간다.
  세션 줄은 마우스를 올리면 바탕색이 부드럽게 바뀌고, 확인 필요 탭에 새로 생긴 줄은 바탕에서
  떠오르듯 나타난다.
- **접힌 그룹 펼치기** — 앱 사이드바에서 접힌 그룹·포크 묶음 안의 세션은 상태를 알려 주지 않는다.
  그래서 위젯이 펼쳐 둔다. 펼친 것은 그대로 둔다.
  - 탭을 누를 때(이미 고른 탭이어도). 항상 동작한다.
  - 자동: Claude 앱이 앞 창이 아닐 때(다른 창에서 일하는 동안이라 사이드바가 눈앞에서 튀지
    않는다), 그리고 위젯에 마우스를 올릴 때(10초에 한 번까지). 접힌 게 없으면 아무것도 안 한다.
    설정 창의 `접힌 그룹 자동으로 펼치기` 로 끈다(기본 켬). `확인 필요` 탭은 확인할 세션이 있으면 개수가
  붙고, 다른 탭을 보고 있어도 노랑(대기)·파랑(읽지 않음)으로 칠해진다. 그동안 창 테두리도 같은
  색이 된다. 탭은 저절로 바뀌지 않는다.
- **확인 필요 탭** — 노란 줄이 위, 파란 줄이 아래다.

  | 줄 | 앱의 상태 | 색 (앱 디자인 토큰 그대로) |
  |---|---|---|
  | 노랑 | `입력 대기 중`, `답변 대기 중` | 바탕 `--cds-fill-warning` `#FAB219`, 글자 `#0B0B0B` |
  | 파랑 | `읽지 않은 응답` | 바탕 `--cds-fill-accent` `#2A78D6`, 글자 `#FFFFFF` |

  사이드바 점 색과 같은 토큰이다. 줄을 누르면 앱이 앞으로 나오고 그 세션이 열린다. 앱에서
  세션을 열면 읽지 않음이 풀리므로 파란 줄도 2초 안에 사라진다. 오른쪽 끝 `✕` 는 그 줄만
  숨긴다. 숨긴 줄은 그 세션이 같은 상태인 동안 숨어 있다가, 상태가 한 번 바뀐 뒤 다시 그
  상태가 되면 또 나온다.

  **방금 확인함** — 확인 필요에서 빠진 세션은 바로 사라지지 않고, 탭 아래 `방금 확인함`
  구분선 밑에 흐리게 30분 동안(최대 5개) 남는다. 잘못 눌렀거나 나중에 다시 보고 싶을 때
  여기서 누르면 다시 열린다. 오른쪽 글씨는 빠진 까닭이다.

  | 글씨 | 뜻 |
  |---|---|
  | `확인함` | 위젯에서 눌러 연 뒤 20초 안에 빠짐(앱이 읽음 처리) |
  | `숨김` | `✕` 로 숨김 |
  | `빠짐` | 그 밖의 까닭(앱에서 직접 열었거나, 답했거나, 그룹이 접혔거나) |

  위젯을 다시 켜면 비워진다. 개수와 탭 색에는 넣지 않는다.

  **보류(나중에 다시 확인)** — 확인 필요 탭의 줄(방금 확인함 줄 포함)을 오른쪽 클릭 →
  `나중에 다시 확인`. 앱 상태와 관계없이 그 세션을 회색 테두리의 `보류` 줄로 붙잡아 둔다.
  오른쪽 클릭 → `보류 해제` 할 때까지 남고, 위젯을 다시 켜도 남는다. 보류 줄은 탭 개수에는
  더하지만 탭 색은 바꾸지 않는다. 그 세션이 다시 확인 필요가 되면 노랑·파랑 줄로만 나온다.

  **접힌 그룹** — 사이드바 그룹을 접어 두면 그 안의 세션 줄은 앱 화면에서 사라져 상태를 읽을
  수 없다. 다만 앱은 접힌 그룹 머리에 "이 그룹에 입력을 기다리는 세션이 있습니다" 라고
  알려 준다. 그러면 그 그룹이 노란 줄 하나로 나온다(`● ✔️ 워크스페이스 · 접힌 그룹 안 · 누르면
  그룹을 펼침`). 누르면 앱에서 그 그룹을 펼치고, 그때부터는 대기 중인 세션이 제 이름으로 나온다.
  접힌 그룹 안에서 실행 중이거나 읽지 않은 세션은 앱이 알려 주지 않아 잡을 수 없다. 탭을 한 번
  누르면 모두 펼쳐져 다 보인다.
- **실행 중 탭** — 노랑·파랑이 아니면서 앱이 상태를 붙인 세션(`실행 중` → `브라우저 사용` →
  `유휴` → `완료됨` 순). 오른쪽에 상태가 초록 글씨로 나온다.
- **즐겨찾기 탭** — 어느 탭에서든 세션 줄을 오른쪽 클릭해 `즐겨찾기에 추가` / `즐겨찾기에서
  빼기`.
  - **구분선**: 즐겨찾기 탭에서 세션 줄이나 빈 곳을 오른쪽 클릭 → `구분선 추가`. 세션 위에서
    하면 그 세션 위에, 빈 곳에서 하면 맨 끝에 생긴다. 이름과 색(없음·빨강·주황·노랑·초록·파랑·
    보라·분홍, 앱 디자인 토큰 400 단계)을 고른다. 구분선을 오른쪽 클릭 → `구분선 편집` /
    `구분선 삭제`. 색을 고르면 구분선 이름과 줄이 그 색이 되고, 그 아래 세션들 왼쪽에 3px 색
    띠가 붙는다(다음 구분선까지). 버튼 바탕은 칠하지 않는다.
  - **끌어서 옮기기**: 즐겨찾기 탭에서 세션이나 구분선을 위아래로 끌면 놓일 자리에 가로선이
    보이고, 놓으면 그 자리로 옮겨진다. 구분선을 옮기면 그 아래 세션들의 색 띠가 따라 바뀐다. 세션 ID로 저장하므로 세션 이름을 바꿔도 그대로 따라간다. 추가한 순서대로 나오고,
  다른 탭에서는 이름 앞에 `★` 가 붙는다. 오른쪽에 그 세션의 지금 상태가 나온다(대기·읽지
  않음은 노랑·파랑 글씨). 접힌 그룹 안의 세션은 `🔷 프로젝트 (접힘)` 처럼 그룹 이름을 붙여
  보여 주고, 누르면 그 그룹을 잠깐 펼쳐 세션을 연 뒤 다시 접는다. 보관했거나 지운 세션은
  `보관됨`·`찾을 수 없음` 으로 흐리게 남으며 누르지 않는다(오른쪽 클릭으로 뺄 수 있다).
- **최근 탭** — 턴이 끝나 아무것도 기다리지 않는 세션을 마지막 활동이 최근인 순서로 보여 준다.
  `24시간 이내` / `1일 전` / `2일 전` … `6일 전` / `1주 이상` 구분선으로 나뉘고, 빈 구간은
  구분선도 없다. 사이드바에 보이는 세션과, 위젯이 전에 본 적이 있는데 지금은 접힌 그룹 안에
  있는 세션이 나온다.
- **스크롤** — 목록이 화면 높이의 60% 를 넘으면 그 높이에서 멈추고 마우스 휠로 넘긴다. 휠 한
  칸에 72px 씩 움직인다.
- **정보 줄** — `desk · 4분째 · 다른 세션 접기·폭 조절 완료` 처럼 세 조각이다.
  - 작업 폴더: 세션 파일의 `cwd` 끝 폴더 이름. 파일을 못 찾으면 사이드바에 보이는 폴더 이름.
  - 시간: 실행 중·브라우저 사용은 지금 턴이 시작된 뒤 `N분째`, 입력·답변 대기는 `N분째 대기`,
    그 밖에는 마지막 활동 뒤 `N분 전`(1분 미만은 `방금`). 세션 파일을 못 찾으면 빠진다.
  - 요약: 사이드바 줄 둘째 줄에 Claude가 써 둔 요약문 그대로.
- **가로 폭** — 창 오른쪽 끝(마우스 모양이 ↔ 로 바뀌는 곳)을 끌어 180~1400px 사이로 바꾼다.
  폭이 넓을수록 긴 세션 이름이 덜 잘린다. 바꾼 폭은 저장되고 크기(작게·보통·크게)를 바꿔도
  유지된다.

글자와 막대 색은 컨텍스트 사용률을 따른다.

| 사용률 | 색 |
|---|---|
| 40% 이하 | 초록 |
| 55% 이하 | 노랑 |
| 70% 이하 | 주황 |
| 그 이상 | 빨강 |

테마는 **다크**(기본)와 **화이트** 둘이다. 배경·글자뿐 아니라 위 네 색도 같이 바뀐다 —
다크용 색은 흰 배경에서 너무 흐려 읽기 어렵기 때문이다. 설정창도 고른 테마를 따른다.

값을 못 읽으면 `알 수 없음` 이라고만 쓴다. 다른 데서 끌어와 채우지 않는다.

## 조작

| 어디서 | 무엇 |
|---|---|
| 머리(컨텍스트 부분) 끌기 | 위치 이동. 자리는 기억된다. 탭·목록에서는 창이 움직이지 않는다 |
| 탭 클릭 | 탭이 바로 바뀌고, 뒤에서 사이드바 접힌 그룹을 모두 펼치고 다시 읽음 (고른 탭을 다시 눌러도) |
| 세션 줄 클릭 | 그 세션으로 이동 (접힌 그룹 안이면 잠깐 펼쳐 열고 다시 접음) |
| 세션 줄 오른쪽 클릭 | 즐겨찾기에 추가 / 빼기 (즐겨찾기 탭이면 + 구분선 추가) |
| 즐겨찾기 탭 빈 곳 오른쪽 클릭 | 구분선 추가 (맨 끝) |
| 구분선 오른쪽 클릭 | 구분선 편집 / 삭제 |
| 즐겨찾기 탭에서 줄 끌기 | 순서 바꾸기 |
| 위젯에 마우스 올리기 | 접힌 그룹 펼치기 (자동 펼치기 켬일 때, 10초에 한 번) |
| 확인 필요 줄의 `✕` | 그 줄만 숨김 (`방금 확인함` 으로 내려감) |
| 확인 필요 탭에서 줄 오른쪽 클릭 | 나중에 다시 확인(보류) / 보류 해제 |
| 마우스 휠 (목록 위) | 목록 스크롤 |
| 창 오른쪽 끝 끌기 | 가로 폭 조절 |
| 머리 오른쪽 클릭 | 지금 앱에서 열린 세션을 즐겨찾기에 추가 / 빼기 + 위젯 메뉴 |
| 트레이 아이콘 왼쪽 클릭 | 숨기기 / 표시 |
| 트레이 아이콘 오른쪽 클릭 | 메뉴 |
| `Esc` | 종료 (창에 포커스가 있을 때) |

메뉴는 `숨기기`(또는 `표시`) · `설정…` · `종료` 셋이다. 트레이 아이콘을 못 만든 경우에는
숨길 방법도 없으므로 `숨기기` 없이 둘만 나온다.

머리를 오른쪽 클릭하면 그 위에 구분선을 두고 지금 앱에서 열려 있는 세션의 항목이 하나 더
나온다. `★ 즐겨찾기에 추가 — <세션 이름>` 또는 `즐겨찾기에서 빼기 — <세션 이름>` 이다. 열린
세션은 앱 창의 문서 이름(`<세션 제목> - Claude Code`)에서 제목을 읽고, 세션 파일과 제목으로
짝지어 찾는다(같은 제목이 여럿이면 보관되지 않았고 가장 최근에 활동한 것). 찾지 못하면
`현재 세션을 찾을 수 없음` 이 흐리게 나온다. 트레이 메뉴에는 이 항목이 없다.

숨기기는 창을 내리는 대신 **투명하게 만들고 클릭이 통과하도록** 한다. 창을 내리면 그 창의
메뉴가 뜨지 않아, 트레이에서 되돌릴 방법이 없어지기 때문이다. 숨긴 상태는 저장하지 않으니
다시 실행하면 보이는 상태로 뜬다.

## 트레이 아이콘

시계 옆 알림 영역에 초록 링으로 상주한다. 마우스를 올리면 현재 사용률과 아랫줄 내용,
확인 필요 세션 수가 풍선으로 뜬다.

**윈도우 11은 새 트레이 아이콘을 처음에 숨긴다.** 시계 왼쪽 `∨` 안에 들어가 있으니,
항상 보이게 하려면 그 아이콘을 작업표시줄로 끌어다 놓는다.

## 설정 창

오른쪽 클릭 → `설정…`. 위젯 옆에서 열리되 화면(작업표시줄 제외) 밖으로 나가면 안쪽으로
밀어 넣는다.

**테마** — 다크 / 화이트. 고르는 즉시 반영되고 그대로 저장된다. 설정창도 새 테마로 다시
그려진다.

**크기** — 작게 / 보통 / 크게. 고르는 즉시 반영되고 그대로 저장된다. `적용` 을 누르지
않아도, `Esc` 로 닫아도 되돌아오지 않으니 되돌리려면 원래 크기를 다시 고른다.
기본 폭은 222, 270, 320 픽셀이다. 글꼴은 숫자 줄이 Consolas, 나머지가 맑은 고딕(Malgun Gothic)이다. 창 오른쪽 끝을 끌어 폭을 바꾸면 그 폭이 우선한다.

**색 구간** — 위 표의 세 경계값. 순서가 뒤바뀌거나 범위를 벗어난 값은 알아서 정리된다.
`기본값` 단추로 되돌린다. `적용` 을 눌러야 저장된다.

**윈도우 시작 시 자동 실행** — 켜면 지금 실행 중인 파일(exe 또는 스크립트)을
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 에 `ClaudeWidget` 이름으로
등록하고, 끄면 지운다. 관리자 권한은 필요 없다. 예전 이름(`ClaudeContextWidget`)으로
등록돼 있으면 첫 실행 때 새 이름으로 옮긴다.

폴더를 옮겨도 다음 실행 때 등록된 경로를 현재 경로로 알아서 고친다. 단 **같은 종류끼리만**
고친다 — exe로 등록해 둔 것을 소스로 한 번 실행했다고 스크립트 경로로 바꿔치지 않는다.

테마·크기·색 구간·창 위치·폭·고른 탭·즐겨찾기·세션별 마지막 그룹은
`claude_widget.state.json` 에 남는다. 이 파일이 없으면 예전
`ctx_widget.state.json` 의 설정을 읽어 이어 쓴다.

## 값을 어디서 가져오나

전부 Windows UI Automation으로 앱 창의 **접근성 정보**를 읽는다. 2초마다 다시 읽는다.

읽기(한 번에 0.3~0.7초)와 사이드바 펼치기·세션 열기는 위젯 창과 다른 스레드에서 한다. 그래서
읽는 동안에도 창이 멈추지 않는다. 목록은 줄을 지우고 다시 만들지 않고 바뀐 글자만 고친다.
탭마다 목록을 따로 두어 탭을 오가도 줄을 다시 만들지 않는다.

**컨텍스트** — 세션 패널(우측)의 `컨텍스트` 카드에 수치가 글자로 들어 있다.

```
컨텍스트
30% 사용됨
300.3k / 1M
```

`300.3k / 1M` 줄을 읽는다. 앱이 고른 세션을 그대로 따라가므로, 다른 세션을 누르면 2초 안에
그쪽 수치로 바뀐다. 상한(1M / 200k)도 여기서 같이 읽는다.

예전 앱은 사용량 원 버튼의 이름에 컨텍스트를 함께 넣었다
(`사용량: … 컨텍스트 325.8k / 1M (33%)`). 2026년 11월 확인 시점의 앱은 더 넣지 않는다.
그래도 그 형식이 다시 나오면 읽는다.

**플랜 한도** — 사용량 원(우측 하단) 버튼의 이름에서 읽는다. 문구는 앱이 대표 한도와 버전에
따라 바꿔 쓴다. 아래 형식을 모두 받는다.

```
사용량: 5시간 한도의 39% 1시간 9분 후 재설정
    → 5시간 한도 39% · 1시간 9분 후 재설정

사용량: 주간 · 전체 모델: 12% (수) 오전 6:00에 재설정
    → 주간·전체 모델 12% · 수 오전 6:00에 재설정

사용량: 주간 · 모든 모델: 80% 7시간 4분 후 초기화
    → 주간·모든 모델 80% · 7시간 4분 후 초기화
```

**확인 필요 세션** — 사이드바의 세션 줄은 버튼이다. 2026-11-09 확인 시점의 구조:

```
버튼 "치이워크 피드백 세션 chiiwork · 연결됨 피드백 파일 준비됨; … chiiwork"
  dframe-fade-label   제목 · 포크 표시 · 연결 상태
    sr-only (숨은 툴팁)  "입력 대기 중" / "읽지 않은 응답" / "실행 중" …  ← 상태는 여기만 본다
  df-meta-slots       세션 요약문 (Claude가 쓴 자유 문장)
    df-meta-place     "chiiwork"                        ← 작업 폴더
버튼 "치이워크 피드백 세션에 대한 더 많은 옵션"           ← 제목
```

숨은 툴팁의 글자가 정확히 `입력 대기 중`·`답변 대기 중`(노랑) 또는 `읽지 않은 응답`(파랑)인
줄만 고른다. 이 문구들은 앱 번역 파일(`ion-dist/i18n/ko-KR.json`)의 상태 이름 그대로이고,
`실행 중`·`유휴`·`완료됨`·`브라우저 사용` 은 고르지 않는다. 요약문은 Claude가 쓰는 자유 문장이라
"…입력 대기 중" 같은 말이 들어갈 수 있다. 그래서 요약문이나 버튼 이름 전체에서 찾으면
기다리지 않는 세션을 잘못 고른다(실제로 있었던 버그). 제목은 바로 뒤 `…에 대한 더 많은 옵션`
버튼에서 얻는다. 툴팁·폴더 조각은 일반 검색(FindAll)에 잡히지 않아서, 원시 트리(raw view)를
직접 따라가 읽는다. 폴더 칸이 없던 예전 앱에서는 둘째 줄(`df-meta-line`)의 마지막 조각을 쓴다.

**세션 파일** — 앱은 Code 세션마다 JSON 파일을 남긴다.

```
%APPDATA%\Claude\claude-code-sessions\<계정>\<조직>\local_<세션>.json
  title, cwd, isArchived, lastActivityAt, lastTurnEdgeAt (ms) …
```

사이드바 줄과는 제목으로 짝짓는다. 같은 제목이 여럿이면(포크) 보관되지 않았고 가장 최근에
활동한 것을 쓴다. 파일이 수백 개라 바뀐 파일만 다시 읽는다(첫 읽기 약 1초, 이후 약 0.2초).
`lastTurnEdgeAt` 은 사용자 메시지가 들어와 지금 턴이 시작된 시각과 일치함을 확인했다.
이 파일에는 모델·추론 강도·권한 모드·마지막 응답 요약도 있지만 위젯은 쓰지 않는다.

## 알아둘 것

- **갱신 시점** — 값은 응답이 끝날 때 갱신된다. 응답이 진행되는 동안에는 직전 값이 보인다.
  창은 2초마다 다시 읽는다.
- **`알 수 없음 · 세션 패널`** — 세션 패널이 닫혀 있으면 컨텍스트 카드가 화면에 없어서
  읽을 수 없다. 앱 위쪽 `세션 패널` 단추로 패널을 열면 2초 안에 나온다. 앱 자체를 못 찾으면
  `알 수 없음` 만 뜨고 아랫줄에 `클로드 앱을 못 찾음` 이 나온다.
- **확인 필요 세션이 안 보일 때** — 사이드바에 그 세션 줄이 그려져 있어야 읽힌다. 사이드바를
  숨기거나, 그룹을 접거나, 중첩된(포크) 세션을 접어 두면 그 안의 세션은 목록에 안 나온다.
  지금 이 위젯과 대화 중인 세션처럼 실행 중인 세션은, 읽지 않음으로 표시해 두어도 실행이 끝나
  다시 그 상태가 될 때까지 나오지 않는다(앱이 상태를 `실행 중` 으로 바꾸기 때문).
- **앱 UI 문구에 기댄다** — 앱 업데이트로 접근성 문구가 또 바뀌면 `알 수 없음` 만 뜨거나
  색 줄이 안 나온다. 그때는 실제 구조를 다시 확인해 `claude_widget.py` 위쪽 정규식과
  상수(`STATUS_CLASS`, `FOLDER_CLASS` 등)를 고치면 된다.
- **줄이 많은 탭** — 줄이 30개를 넘는 탭은 처음 열 때 0.3초쯤, 그 뒤에는 0.1초쯤 걸린다.
  Tk가 줄의 글자 칸마다 윈도우 창을 하나씩 그리기 때문이다.
- **에러 로그** — 예기치 못한 오류는 `claude_widget.error.log` 에 쌓인다. 창이 조용히
  이상해지면 여기부터 본다.

## 파일

| 파일 | 무엇 |
|---|---|
| `claude_widget.py` | 본체 전부 (읽기·창·트레이·설정) |
| `claude_widget.ico` | 창·트레이·실행 파일 아이콘 |
| `make_icon.py` | 위 아이콘을 그린다 |
| `build_exe.py` | 독립 실행 파일을 만든다 |
| `클로드위젯.cmd` | 소스로 실행 |

아래는 저장소에 없다. 실행하거나 빌드하면 생긴다.

| 파일 | 무엇 |
|---|---|
| `dist\ClaudeWidget.exe` | 빌드 결과 (약 11MB) |
| `claude_widget.state.json` | 설정 |
| `claude_widget.error.log` | 오류 기록 (생길 때만) |
| `claude_widget.debug.log` | `--debug` 로 실행했을 때만 |

## 개발

```bash
python claude_widget.py --self-check   # 라벨 파싱·세션 줄·색 구간·테마·크기·좌표·읽기 스레드·줄 재사용 점검
pythonw claude_widget.py --debug       # 드래그 로그를 claude_widget.debug.log 에
python make_icon.py                 # 아이콘 다시 그리기
python build_exe.py                 # exe 다시 빌드 (PyInstaller 필요)
```

**한 파일(onefile)로 만든다** — 복사할 게 하나뿐이라서. 대가는 시작 속도다. 한 파일은
실행할 때마다 내용물을 임시 폴더에 푼다. 같은 코드로 각각 3~4회 실측한 값:

| 방식 | 창이 뜨기까지 | 디스크 |
|---|---|---|
| 한 파일 (지금) | 평균 1160 ms | 10.8MB (압축) |
| 폴더 (`--onedir`) | 평균 244 ms | 24.7MB |

시작이 거슬리면 `build_exe.py` 의 `--onefile` 을 `--onedir` 로 되돌리면 된다. 그때는
`dist\ClaudeWidget\` 폴더째 옮겨야 한다.

빌드 크기는 `build_exe.py` 의 `EXCLUDES` 가 좌우한다. 특히 **numpy는 반드시 빼야 한다** —
`comtypes._npsupport` 가 numpy가 깔려 있으면 무조건 import해서, 쓰지도 않는 numpy와
OpenBLAS가 26MB나 딸려 들어간다. 남은 용량은 대부분 파이썬 런타임과 Tcl/Tk라 더 줄이려면
Tk를 걷어내야 한다.

## 만듦새

개인용으로 만든 도구다. 앤트로픽과 무관하고, 클로드 앱을 고치거나 후킹하지 않는다 —
화면에 이미 떠 있는 접근성 텍스트를 읽을 뿐이다. 앱이 그 문구를 바꾸면 동작이 멈출 수 있다.
